# Abolaji Abdusawmod Akande — Software Engineer Portfolio

Premium cinematic portfolio for a full-stack software engineer — dark lab aesthetic, amber identity `#0c0a09 / #fbbf24 / #fb923c`, generative ambient background.

**Stack:** Next.js 16 · React 19 · Tailwind v4 · Framer Motion · TypeScript

**Typography:** Teko (display condensed) + Cormorant Garamond (editorial serif) + Instrument Sans (body) + JetBrains Mono (mono) — rare, world-class, zero AI-generic fonts.

**Highlights**
- `AmbientBackground` — hero-contained generative branching tree (canvas, 30fps, desktop-only, respects `prefers-reduced-motion`)
- `Intro` 3600ms cinematic entrance
- Premium glass nav, subtle magnetic/tilt physics, marquee ticker, case-study project pages at `/projects/clockhost` and `/projects/nairaguard`
- `Say hello → mailto:sawmodabolaji@gmail.com` inside Contact
